# e-bazary

Boutique en ligne de démonstration (Madagascar) : meubles, mode, électronique, beauté et plus encore.

Site en ligne : https://e-bazary-mada.vercel.app

## Fonctionnalités

- Boutique avec filtres par catégorie, recherche et tri
- Panier, favoris, aperçu rapide des produits
- Paiement avec code promo (`BRILLANT2026` : -10 %) et numéro de commande
- Suivi de commande, compte de démonstration, newsletter, formulaire de contact
- Navigation SPA, version mobile avec barre de navigation en bas, mode sombre

Aucun backend : panier, favoris, compte et commandes sont enregistrés dans le navigateur (localStorage).

## Stack

React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, Framer Motion, React Router.

## Lancer le projet

```sh
npm install
npm run dev      # serveur de développement
npm run build    # build de production
npm test         # tests
```
